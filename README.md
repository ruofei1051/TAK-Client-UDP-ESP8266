# TAK-Client-UDP-ESP8266

ESP8266 上的 ATAK 客户端。上电后自己开一个 WiFi 热点，手机连上后，用 UDP 交换位置和聊天，不需要 TAK Server。

本机没有 GPS。位置坐标写在程序里的 `DEVICE_LAT`、`DEVICE_LON`。时钟在收到第一条带时间的 ATAK 报文后自动对齐；对齐之前发出的位置，ATAK 会当成过期数据。

## 热点

| 项目 | 值 |
| --- | --- |
| 名称 | `TAK-Client-UDP-ESP8266` |
| 密码 | `12345678` |
| 本机地址 | `192.168.4.1` |
| 配置页 | http://192.168.4.1 |

手机提示“无互联网”时，选择保持连接。

## 通信

| 用途 | 地址 | 方式 |
| --- | --- | --- |
| 成员位置（SA） | `239.2.3.1:6969` | UDP 组播 |
| All Chat Rooms 群聊 | `224.10.10.1:17012` | UDP 组播 |
| 私聊 | `192.168.4.1:17012` | UDP 单播 |

位置大约每 5 秒广播一次，内容是 CoT。默认身份是呼号 `ESP8266-TAK`、小队颜色 Cyan、角色 Team Member。ATAK 不要连接 TAK Server，走本地 Mesh。

## 配置页

浏览器打开 http://192.168.4.1 ，可以修改：

- 呼号（最多 20 字节，可以用中文）
- 小队颜色
- 角色

保存后写入 Flash，断电再开仍然有效。下一次位置广播会带上新身份。

## 私聊控制 IO5

IO5 接 LED：高电平亮，低电平灭。上电默认灭。只有私聊会触发，群聊不会。

| 私聊内容 | 灯 | 回复 |
| --- | --- | --- |
| 开灯、打开灯、灯打开、把灯打开、开一下灯、`turn on`、`light on` | 亮 | 收到，已开灯 |
| 关灯、关闭灯、关掉灯、灯关闭、把灯关、`turn off`、`light off` | 灭 | 收到，已关灯 |
| 其他私聊 | 不变 | 收到 |

同一条消息里开灯和关灯都有时，以靠后的那个为准。回复发回对方的 UDP `17012`。

聊天正文里出现 `Roger` 会闪板载灯，出现 `callRESTART` 会重启。

## 串口

波特率 `115200`。上电后会打印热点名称、密码、IP、呼号，以及收到的原始 UDP 数据。

## 编译和烧录

用 Arduino IDE 打开本文件夹，开发板选 ESP8266（核心 3.1.2 已验证过）。依赖都在开发板核心里：

- ESP8266WiFi
- ESP8266WebServer
- EEPROM

上传失败并提示 `Timed out waiting for packet header` 时，先关掉串口监视器，按住 FLASH（或 BOOT / IO0），点一下 RST，松开 RST 后再松开 FLASH，立刻重新上传。
